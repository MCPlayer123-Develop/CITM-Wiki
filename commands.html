命令

"CHESTS IN THE MAPS 最神奇的咒语。" —— hezhibao
此页面仅适用于 C++ Edition。命令（Command）是要开启作弊从而修改游戏数据或开发的工具，目前有 8 种命令（Alpha 0.9.1 已移除 eggs_mcplayer123 彩蛋，因此不再包含彩蛋命令）。

C++ Edition 命令

/kill

杀死指定生物。mob 可填 chest:zombie、chest:skeleton、chest:arrow、chest:lava_zombie、chest:burn_skeleton、chest:burn_arrow、chest:blaze、chest:enderman、chest:player；第二个参数填序号可清除单个个体，填 all 可清除该类型的全部个体。Alpha 0.9.1 起支持清除箭矢与火矢（chest:arrow / chest:burn_arrow）。第一参数直接填 all 会清空主世界、下界、末地的全部生物并杀死玩家，死亡信息为 "Player was killed."；/kill chest:player 也会显示该信息。

/kill <mob> <id/all>

/tp

传送玩家

/tp <x> <y>

/give

给予物品

/give <item> <count>

/gamerule

设置规则

/gamerule <rule> <value>

/setblock

更改方块。维度可选 chest:overworld、chest:nether、chest:the_end（末地为 Alpha 0.9.1 新增）；末地方块可用 chest:end_stone、chest:end_void、chest:end_crystal、chest:ender_chest、chest:obsidian。

/setblock <dimension> <x> <y> <block>

/gamemode

设置游戏模式

/gamemode <mode>

/summon Alpha 0.9.1

在指定坐标生成一只生物，并指定其初始血量、朝向与敌对状态。生物可填 chest:zombie、chest:skeleton、chest:arrow、chest:lava_zombie、chest:burn_skeleton、chest:burn_arrow、chest:enderman；hostile 填 true 时生成即处于敌对状态，主要用于测试与调试。

/summon <mob> <x> <y> <health> <facing> <hostile>

/help

帮助

/help
